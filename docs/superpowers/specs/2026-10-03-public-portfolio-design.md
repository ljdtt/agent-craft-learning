# Agent Craft 在线作品集设计

日期：2026-10-03  
状态：用户于 2026-10-03 回复“继续”，已批准实施

## 1. 目标

把当前本地可运行的 Agent Craft 学习项目整理成两个可以分享的入口：

1. 公开 GitHub 仓库，用于展示源码、学习成果、原作者署名和运行说明。
2. 公开 Streamlit 网站，用于演示航空客服多智能体系统。

在线作品允许访客真实调用模型，但每个浏览器会话最多提交 5 轮对话，以降低误用和 API 费用。所有退票、改签和天气结果都是教学演示，不连接真实业务系统。

## 2. 设计原则

- 保留课程代码，另外增加云端作品入口，避免破坏已经完成的本地 MCP 学习流程。
- 真实 API Key 只保存在 Streamlit Cloud Secrets 中，不进入 Git 历史。
- 页面明确说明原项目作者、许可证、个人修改范围和模拟业务性质。
- 云端依赖保持精简，不下载本项目其他章节使用的本地嵌入模型。
- 优先保证访问者能稳定体验退票、改签、天气查询和 Agent 转接。

## 3. 发布结构

### 3.1 GitHub 仓库

建议仓库名：`agent-craft-learning`

仓库公开展示：

- 模块 01～13 的学习代码。
- Windows、Conda 和依赖适配结果。
- 在线作品的入口及部署说明。
- 原项目 `Annyfee/agent-craft`、原作者 Annyfee 和 MIT License。

仓库排除：

- `.env` 和 Streamlit Secrets。
- 下载的模型文件。
- Chroma、FAISS 和 SQLite 运行数据。
- 缓存、日志及个人排错文档。

### 3.2 Streamlit 在线作品

新增独立的云端作品入口，放在 `m13_streamlit` 目录中。Streamlit Community Cloud 从该入口启动，并优先使用同目录下的精简依赖文件。

页面保留：

- TriageAgent、RefundAgent、ChangeAgent。
- 退票、改签和天气工具。
- Agent 转接状态。
- 流式输出。
- 工具调用记录。
- 用户画像和消息统计。
- 清空会话。

页面新增：

- “教学演示，不执行真实退票或改签”提示。
- 每个会话剩余体验次数。
- 输入长度提示。
- GitHub 源码和原项目链接。
- 缺少密钥、模型请求失败和达到限额时的友好错误信息。

## 4. Agent 与工具结构

现有本地学习版继续通过 `http://127.0.0.1:8001/mcp` 连接天气 MCP Server，不改变模块 10～12 的演示方式。

云端作品版使用 Agents SDK 的 Python `function_tool` 实现天气演示工具：

```text
访客问题
  -> Streamlit 页面
  -> TriageAgent
  -> 退票工具 / 改签工具 / 天气工具
  -> 流式回答
```

天气工具返回固定的教学数据，避免依赖本机端口或额外云服务。工具调用仍会出现在页面记录中，能够展示 Agent 自主选择工具的过程。

## 5. 密钥和配置

本地运行继续支持根目录 `.env`。

云端使用 Streamlit Cloud Secrets 保存：

```toml
OPENAI_API_KEY = "真实的 DeepSeek API Key"
```

代码通过环境变量读取密钥。仓库只提交示例配置，不提交真实值。应用启动时若没有密钥，应显示配置说明并停止模型初始化，不能输出密钥内容。

## 6. 费用控制

第一版采用适合作品演示的轻量限制：

- 每个 Streamlit 会话最多提交 5 轮对话。
- 单次输入最多 300 个字符。
- 达到上限后关闭输入框并显示说明。
- 每次只处理一个问题，避免重复提交。

该限制主要防止普通访客误操作，不能抵抗访客更换浏览器或主动绕过。仓库和页面必须如实说明这一点。真正的全站硬限额需要外部数据库、鉴权或 API 网关，不属于第一版范围。发布者应同时在模型服务商账户中保持较小余额或设置可用的费用保护。

## 7. 会话与数据

- 每位访客获得随机会话 ID。
- 对话状态仅用于当前演示会话。
- SQLite 文件写入临时运行目录，不提交 Git，也不承诺跨重启保存。
- 页面提醒访客不要输入身份证、手机号、订单号等真实隐私信息。
- 清空对话时同步重置 Agent、消息、工具日志和临时会话记录；体验次数不重置，避免通过按钮绕过本会话上限。

## 8. 依赖与云端资源

在线作品使用独立的精简依赖列表，只包含：

- `streamlit`
- `openai`
- `openai-agents`
- `nest-asyncio`
- `python-dotenv`

不安装 RAG 章节使用的 Torch、Transformers、Sentence Transformers、Chroma 和 FAISS，避免云端构建缓慢或超出内存限制。

部署 Python 版本与当前已验证环境保持在 3.11。

## 9. 错误处理

- 缺少 API Key：页面显示部署者配置提示，不启动 Agent。
- 模型接口超时或余额不足：保留用户问题并显示可理解的失败信息，允许稍后重试。
- 工具异常：显示“演示工具暂时不可用”，不暴露堆栈或环境信息。
- SQLite 初始化失败：退回当前页面会话内存，保证基本体验可继续。
- 达到会话上限：停止新请求，不继续调用模型。

## 11. 验收标准

### 自动检查

- 所有待上传 Python 文件通过语法编译。
- 云端入口在没有真实密钥的测试环境中能够加载配置错误页面。
- 输入为空或超过 300 字符时不调用模型。
- 第 6 轮输入不调用模型。
- `.env`、Secrets、模型、数据库和缓存没有被 Git 跟踪。
- 精简依赖能够在 Python 3.11 中解析安装。

### 人工体验

- 打开公开链接能够看到项目说明和模拟业务提示。
- “我想退票”会转接 RefundAgent 并调用退款工具。
- “我想改签”会转接 ChangeAgent 并调用座位工具。
- “杭州今天天气怎么样”会调用云端天气工具。
- 转接和工具调用能在界面中查看。
- 刷新或清空会话不会泄露其他访客的消息。
- GitHub README 的在线体验按钮能打开部署页面。

## 12. 不在第一版范围内

- 真实航空订单、支付或退款系统。
- 真实天气 API。
- 云端独立 MCP Server。
- 用户注册、登录和持久账户。
- 可抵抗恶意攻击的全站计费网关。
- 自定义域名和商业级监控。
